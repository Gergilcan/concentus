Pensa en Dify o n8n, però per a agents que llegeixen i canvien codi — a la teva pròpia màquina, amb un verificador que pot dir que no.

Concentus és una aplicació d'escriptori per connectar flows multiagent en un llenç i executar-los sobre els teus propis repositoris, les teves pròpies bases de dades i la subscripció de Claude que ja tens a la teva màquina. 01 · L'Studio

El flow que dibuixes és el flow que s'executa.

03 · Executar i dirigir

Mira'l treballar. Agafa el volant.

Una execució es transmet mentre passa: la sortida de cada agent, filtrable agent a agent, cadascun amb el seu color al llarg de tota la transcripció. Demana a un agent que aprovi el seu pla abans d'actuar, i res no toca el teu disc fins que tu ho diguis.

⚖ Verificat

El que el verificador adversarial va descartar, de tot el que va jutjar. La sortida rebutjada mai no arriba al merge.

⟳ Reintentat

Una execució que només passa després de reintentar-ho tot no està sana — té sort. La consola diu quina de les dues.

⧗ Paral·lel

Temps real davant la mateixa feina feta de cap a cap. Aquest ×factor és el que realment va guanyar el repartiment en paral·lel.

⟲ Replay

Passa les sortides gravades d'una execució acabada pel flow tal com està dibuixat avui — el llenç envolta cada bloc el destí del qual canviaria. Decisions, no sortides; no s'executa res.

04 · Casos d'ús

Connecta l'equip segons la feina.

Els mateixos dotze blocs, disposats per a la feina que tens al davant. Cap d'aquests necessita una línia de codi de cola — només un dibuix diferent.

linear→ lead→ befe

Lliurar des d'un tiquet

Agafa una història de Linear, reparteix la feina de backend i de frontend entre subagents, i puja els canvis.

repo→ revisor

Auditar un diff

Un agent revisor rastreja els fitxers canviats buscant errors de correcció i problemes de seguretat, ordenats per gravetat.

postgres→ agent

Respostes amb dades reals

Un agent consulta la teva base de dades i respon amb els números reals — no amb una suposició treta de les dades d'entrenament.

El tracte

Els flows s'executen mentre l'app està oberta — no a les 3 de la matinada en un servidor.

Aquest tracte és justament la gràcia. Fer anar la CLI claude a la teva màquina és el que arriba a la teva sessió de Claude, als teus repositoris i a les carpetes del teu propi disc — res del qual pot veure un contenidor allotjat. Un flow programat o activat per correu salta quan la teva màquina està encesa i Concentus obert.

05 · Instal·lar

Instal·la'l. Obre'l. Aquesta és tota la configuració.

L'app porta el seu propi runtime de Java i el seu propi PostgreSQL, així que no hi ha requisits previs ni res a configurar — i no toca cap dels dos si ja els tens instal·lats. La primera arrencada et demana crear un compte, i això és tota la configuració.

O des d'un gestor de paquets — sense el mur de l'SmartScreen: scoop bucket add concentus https://github.com/Gergilcan/concentus && scoop install concentus · winget install concentus · brew tap gergilcan/concentus && brew install --cask concentus · npx concentus

La interfície parla anglès, castellà i català — segueix l'idioma del teu sistema a la primera arrencada.

Windows

Instal·lador

Una instal·lació per usuari — sense permisos d'administrador.

Que l'SmartScreen mostri un avís és normal: l'instal·lador de Windows encara no està signat. Prem Més informació → Executa de totes maneres — o instal·la amb scoop, winget o npx concentus, que se salten l'avís del tot.

Un sol cop

Inicia sessió a Claude un cop, a la teva màquina. Concentus executa els teus flows a través de la CLI claude a la qual ja pertany aquesta sessió — per això no hi ha cap API key per enganxar. Anthropic mesura l'ús no interactiu de Claude Code en la seva pròpia bossa, separada de les teves sessions interactives; la pàgina d'Ús mesura el que ha consumit aquesta màquina, i un flow pot recórrer a una API key o a un model local quan s'esgota.

Tota la resta, inclosa la configuració del webhook, és al README i a la documentació.
